# Handoff review

The instruction package received a fresh-implementer review before delivery. Four material issues were identified and corrected:

1. Independent reference qualification is now required per primary item, with unadjudicated attestations/proxies kept exploratory. Missing independent evidence leads to inconclusive status, not self-certified gold.
2. End-to-end default-provider evaluation and supplied-pronunciation evaluation are now separate. Oracle phones must not silently enter the primary score.
3. Identity combines spelling, intended pronunciation and accent. Multiple readings are valid separate items within one lexical split group; mapping order is not treated as an error.
4. The seven-run budget confirms a selected recipe against letters, not C against B. P2G's incremental effect and pretraining-versus-replay remain exploratory/unisolated.

This review checked the handoff's consistency and execution logic. It did not run the future implementation, train models, validate local panel labels or guarantee the proposed method will improve quality.
